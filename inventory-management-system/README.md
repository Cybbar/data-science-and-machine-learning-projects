
# Book Inventory Management System

A command-line inventory management application built with Python for managing book records and stock information.

## Features

- Add and remove books.
- Search books by title, author or ISBN.
- Update book quantities and prices.
- Display books alphabetically.
- Save and load inventory records using JSON.
- Automatically save inventory when exiting.

## Technologies

- Python
- JSON
- Dictionaries
- File Handling

## How to Run

1. Make sure Python 3 is installed.
2. Open the project directory in your terminal.
3. Run:

```bash
python inventory.py
```

## Project Purpose

This project demonstrates Python programming concepts, including functions, dictionaries, conditional statements, loops, exception handling and JSON file operations.
